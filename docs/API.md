# API –  v2 2/11/26
## Διεπαφές με REST των 4 συστημάτων: Πληκτρολόγιο χρήστη, Κεντρικό σύστημα, Ανελκυστήρας και Σύστημα αξιολόγησης.
Αλλαγές απο v1 -> ακριβή endpoints, κωδικοί απάντησης, url's , 

## 0. Γενικά 
- Πρωτόκολλο: HTTP
- Κωδικοποίησης χαρακτήρων: UTF-8 (JSON) 
- Όροφοι: 0 (ισόγειο) εως Ν-1, όπου Ν ειναι το πλήθος των ορόφων όπως ορίζεται απο το configuration και την εκφώνηση  (3-200)
- Ανελκυστήρες: Κάθε ανελκυστήρας έχει ένα αναγνωριστικό το οποίο είναι ένα γράμμα με τιμές A - T, καθώς η εκφώνηση ορίζει 2 - 20 ανελκυστήρες 
- URl's: η μορφή των διεθύνσεων είναι localhost... Προεπιλεγμένη πόρτα για το κεντρικό σύστημα -> 3000 

### Κωδικοί απάντησης 
|Κωδικόσ|Σημασία|πότε|
|--|--|--|
|..|..|..|
| 200 | Επιτυχία | το αίτημα εκτελέστηκε |
| 202 | Έγινε αποδεκτό | ξεκίνησε εκτέλεση που συνεχίζεται (πχ δεν έχει ολοκληρωθεί ακόμα) |
| 400 | Λάθος αίτημα | εκτός ορίων μεταβλητή, λάθος τύπος ή  Λάθος τιμή  |
| 404 | Δεν βρέθηκε | άγνωστο id |
| 405 | Λάθος μέθοδος | π.χ. πχ POST Request σε σημείο που έχει μόνο GET |
| 503 | Μη διαθέσιμο | δεν υπάρχει διαθέσιμος ανελκυστήρας ή ένα υποσύστημα δεν απαντάει |


## 2. Κεντρικό σύστημα
### 2.1 Αίτημα από Πληκτρολόγιο 
- Δέχεται τις 2 μεταβλητές απο πού ξεκινάει ο χρήστης και πού θέλει να πάει 
- τρέχει τον αλγόριθμο elevator_dispatch για να υπολογίσει τον βέλτιστο ανελκυστήρα 
- Επιστρέφει τον αριθμό του βέλτιστού ανελκυστήρα 
### 2.2 Επικοινωνία ανελκυστήρα
- Ζητάει την κατάσταση του ανελκυστήρα 
- Στέλνει στον επιλεγμένο ανελκυστήρα τι κίνηση πρέπει να κάνει 
- Στέλνει στον ανελκυστήρα εντολή για στάση 

## 3. Ανελκυστήρας
 - Δέχεται αίτημα για την κατάστασή του
- Επιστρέφει τον όροφο που βρίσκεται και την κατεύθυνση και την κατάστασή του
- Δέχεται από το κεντρικό σύστημα σε ποιόν όροφο πρέπει να πάει
- Δέχεται εντολή για στάση

## 4. Πληκτρολόγιο Χρήστη 
- Ο χρήστης πληκτρολογεί σε ποιόν όροφο θέλει να πάει 
- στέλνει στον κεντρικό εγκέφαλο 2 μεταβλητές where_from, where_to στο κεντρικό σύστημα
- δέχεται απο το κεντρικό σύστημα σε ποιό ανσανσέρ πρέπει να πάει ο χρήστης
- Εμφανίζει το ανσανσέρ
